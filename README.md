# 구름고래 항해기 — UX 프로토타입 v0.1

three.js로 만든 모바일 웹(PWA) 프로토타입입니다. 기획 문서는 [docs/](docs/README.md)에 있습니다.

## 들어 있는 것
| 화면 | 내용 |
|---|---|
| 시작 화면 | 로고, 첫 터치에서 소리 켜기 |
| 항해 일지 | 접속하지 않은 시간만큼 모인 보상 (최대 12시간) |
| 누리 등 위 | 픽셀 2.5D 렌더링, 구름바다·해무·반짝임, 하늘 시계(실제 2시간 = 하늘 하루), 탭 이동 |
| 농사 | 이끼흙에 별딸기 심기 → 90초 뒤 수확 |
| 꾸미기 | 격자 위에 소품 6종 놓기·치우기·돌리기 |
| 돌보기 (ASMR) | 따개비 떼기, 거품 목욕, 깃털 간지럼(무지개 재채기·오늘의 운세), 심장 소리 호흡 |
| 이웃 | 데모 고래지기 3명, 인사 나누기, 꼬리 인사 |
| 항해·가방·설정 | 목적지 고르기, 소지품, 소리·하늘 시간 미리보기 |

- 가로·세로 모두 지원합니다. 화면을 돌리면 카메라가 돌아 누리의 긴 몸이 화면의 긴 쪽에 옵니다.
- 음원 파일이 없습니다. BGM과 효과음은 모두 Web Audio로 실시간 합성합니다.
- 저장은 브라우저 localStorage에 합니다. 실시간 온라인은 아직 없고, 이웃은 데모입니다.

## 실행
```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서 표시된 주소로 접속)
npm run build      # dist/ 에 정적 파일 생성
npm run icons      # 앱 아이콘 다시 만들기
node scripts/shots.mjs   # 화면 캡처 (playwright 필요)
```

## 배포
정적 파일만 있으면 됩니다. 빌드 결과(`dist/`)는 `gh-pages` 브랜치에 올라가고, GitHub Pages가 그 브랜치를 배포합니다.
- 저장소 Settings → Pages → Source: **Deploy from a branch**, Branch: **gh-pages / (root)**
- `.github/workflows/deploy.yml`이 있으면 main에 푸시할 때마다 자동으로 `gh-pages`를 갱신합니다.

## 구조
```
src/
  main.ts        장면 조립, 입력, 게임 흐름
  core/          하늘 시계, 저장·방치 보상
  render/        픽셀 파이프라인, 구름바다, 해무, 하늘, 입자
  world/         누리, 등 위 격자·소품, 주인공, 섬, 이웃 고래
  care/          ASMR 돌보기 화면
  audio/         절차적 사운드 엔진
  ui/            HUD, 패널
```
