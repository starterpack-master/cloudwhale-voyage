# 구름고래 항해기 — 프로토타입 v0.2

2D 탑다운 도트 게임으로 다시 만든 모바일 웹(PWA) 프로토타입입니다. 엔진은 Phaser 3, 모든 그림은 코드로 한 픽셀씩 찍었습니다. 기획 문서는 [docs/](docs/README.md)에 있습니다.

## 첫날 흐름 (약 10분)
1. **프롤로그:** 노을 진 퇴근길, 어릴 적 노래를 흥얼거리자 구름 너머의 고래가 대답한다.
2. **누리의 등:** 빨판상어 뽀뽀의 안내로 별딸기 심기 → 물 주기 → 누리 돌보기(따개비 떼기) → 수확 → 누리에게 먹이 주기
3. **등불항:** 등대지기 모아 할머니에게 대고요와 하늘노래 이야기를 듣고, 작은 숲섬에서 하늘유목 3개 줍기
4. **첫 가구:** 받은 벤치를 누리 등에 놓으면 누리가 처음으로 노래를 흥얼거림 (노래조각 1/5)

- 화면 왼쪽 위의 **지금 할 일**과 노란 **화살표**가 다음 행동을 알려 줍니다. 대상이 화면 밖에 있으면 화살표가 가장자리에서 방향을 가리킵니다.
- 이동: 화면을 누르면 그 자리로 걸어갑니다 (PC는 WASD·방향키도 가능).
- 가로·세로 화면 모두 지원합니다. 진행은 브라우저에 자동 저장됩니다.

## 실행
```bash
npm install
npm run dev              # 개발 서버
npm run build            # dist/ 에 정적 파일 생성
node scripts/play.mjs    # 첫날 흐름을 자동으로 끝까지 진행하며 화면 캡처 (playwright 필요)
```
`preview.html`은 도트 그림을 한눈에 보는 개발용 페이지입니다.

## 구조
```
src/
  art/     도트 그림 (팔레트·도구, 캐릭터, 지형, 건물·소품, 누리)
  game/    장면(프롤로그, 월드), 맵, 이야기·퀘스트, 저장
  ui/      지금 할 일, 가방 줄, 대화창, 도트 테두리
  care/    누리 돌보기 (ASMR) 화면
  audio/   절차적 사운드 엔진 (음원 파일 없음)
```

## 배포
빌드 결과(`dist/`)를 `gh-pages` 브랜치에 올리면 GitHub Pages가 배포합니다.
