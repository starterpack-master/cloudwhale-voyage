# 구름고래 항해기 (가제)

> 오랜만에 올려다본 하늘에서, 아기 고래가 당신의 노래에 대답했다.

| 항목 | 내용 |
|---|---|
| 장르 | 힐링 생활 시뮬레이션 + 고래 등 위 건축 + 협동 모험 (온라인) |
| 플랫폼 | 모바일 웹 PWA (가로·세로 모두 지원, 기본 가로), PC 브라우저도 지원 |
| 기술 | three.js 픽셀 2.5D, 서버 없이 유저끼리 연결(P2P) + 관리형 백엔드 |
| 타겟 | 예쁜 색감의 힐링·꾸미기 게임과 서정적인 이야기를 좋아하는 여성 유저 |
| 톤 | 밝은 파스텔 색감과 귀여운 캐릭터 디자인 + 신비롭고 세련된 판타지 세계·이야기 |
| 레퍼런스 | 스타듀밸리(생활), 래프트(떠다니는 기지), 마인크래프트(자유 건축), 동물의 숲(이웃·비동기 소통), 지브리·Sky: 빛의 아이들·저니·스피릿페어러(분위기·이야기) |

## 소개
땅들이 구름 아래로 가라앉은 하늘 세계. 사람들이 고래의 노래에 대답하지 않게 된 뒤, 고래들은 30년째 깊은 잠에 들어 있어요. 바쁜 하루 끝에 오랜만에 하늘을 올려다본 '나'는, 노래를 배우지 못한 아기 구름고래 **누리**의 등 위에서 눈을 떠요. 누리 등에 밭을 일구고 집을 짓고, 누리를 씻기고 쓰다듬고 재우며 함께 하늘을 항해해요. 잠든 고래를 하나씩 깨울 때마다 누리는 하늘노래의 한 소절을 되찾으며 자라고, 가라앉았던 섬들이 색을 되찾으며 떠올라요. 다른 고래지기들과 나란히 헤엄치고, 함께 고래를 깨우고, 등과 등을 이어 장터를 열어요. 접속하지 않는 동안에도 누리는 꿈을 꾸며 천천히 헤엄쳐요.

## 디자인 기둥
1. **귀여운 얼굴, 깊은 하늘** — 캐릭터는 둥글고 사랑스럽게, 세계와 이야기는 신비롭고 세련되게.
2. **손끝 교감** — 누리를 만지고 씻기고 재우는 ASMR 손맛.
3. **벌 없는 쉼** — 아무것도 시들거나 아프지 않다. 5분만 놀아도 충분하다.
4. **함께라서 더 풍성하게** — 같이 하면 더 즐겁지만, 혼자여도 모든 이야기를 즐길 수 있다.
5. **빛나는 하늘, 나만의 마을** — 신비로운 빛 속, 고래 등 위에 짓는 나만의 집.

## 용어
| 용어 | 뜻 |
|---|---|
| 구름바다 | 고래들이 헤엄치는 구름 바다. 주 무대 |
| 잊힘의 바다 | 구름바다 아래. 대답받지 못한 것들(부치지 못한 편지, 하지 못한 말, 잃어버린 꿈)이 가라앉는 곳 |
| 별의 바다 | 구름바다 위. 별이 물고기처럼 헤엄친다 |
| 하늘노래 | 고래가 부르고 사람이 답하며 구름을 엮던 노래. 여섯 소절 |
| 대고요 | 30년 전, 대답을 듣지 못한 고래들이 조용해지다 끝내 잠든 일 |
| 고래지기 | 고래와 함께 사는 사람. 플레이어의 칭호 |
| 노래조각 | 소절의 음 하나이자 이야기 수집품. 5개가 모이면 소절 하나 완성 |
| 잔향 / 울림 | 대답받지 못한 노래와 마음이 그림자처럼 남은 것 / 응답을 받은 잔향이 변한 작은 빛의 정령 |
| 선단 | 함께 항해하는 친구 모임 (최대 6명) |
| 조가비 | 기본 화폐 |
