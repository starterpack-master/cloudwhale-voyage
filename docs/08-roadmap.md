# 08. 개발 로드맵

## 전략: 분위기 먼저
이 게임의 승부처는 **"켜자마자 아름답고 편안한 느낌"**이에요. 시스템보다 먼저 구름바다·해무·누리·ASMR 케어·음악의 느낌을 검증하고, 그 위에 시스템을 쌓아요.

## 단계
| 단계 | 목표 | 범위 | 완료 기준 |
|---|---|---|---|
| M0 분위기 | "아름답고 신비로운가?" | 픽셀 파이프라인, 구름바다, 해무, 낮·밤, 헤엄치는 누리, 등 위 걷기, 가로(기본)·세로 전환, BGM 1곡 | 폰에서 부드럽게 돌아가고, 멍하니 보고 싶은 화면 |
| M1 케어 | "만지고 싶은가?" | ASMR 케어 3종 (따개비, 거품 목욕, 무지개 재채기), 소리·진동·반응 | 테스터가 시키지 않아도 계속 문지른다 |
| M2 생활 | "매일 하고 싶은가?" | 농사, 낚시, 표류물, 인벤토리, 제작, 격자 건축, 저장, PWA 설치·오프라인 | 30분 루프가 자연스럽게 돈다 |
| M3 방치 | "다시 오고 싶은가?" | 재우기·자면서 항해, 수염 필터, 항해 일지, 망보기·대도약 | 다음 날 켰을 때 설렌다 |
| M4 함께 | "같이 하면 더 즐거운가?" | P2P 해역 채널, 이모트, 고래 인사, 방문, 선단, 구름방울 고리 | 둘이서 10분 놀고 웃는다 |
| M5 이야기 | "다음이 궁금한가?" | 프롤로그 + 1장, NPC 4명, 노래조각, 해솔 깨우기 | 비공개 테스트 시작 |
| M6 소셜 | "하늘에 사람이 사는 느낌인가?" | Supabase: 친구, 우편, 유리병, 방명록, 설계도, 클라우드 저장 | 공개 베타 |
| M7 이후 | 확장 | 2~6장, 시즌 이벤트, 새 해역 | 정기 업데이트 |

## 에셋 만드는 방법
| 종류 | 방법 |
|---|---|
| 3D 월드·가구 | 복셀(MagicaVoxel 등)로 만들고, 저해상도 렌더로 도트 느낌 통일 |
| 캐릭터 | 32×32 도트 스프라이트, 옷은 레이어로 |
| 누리 | 로우폴리 모델 + 툰 셰이더 + 표정 텍스처 |
| UI 아이콘 | 16×16 / 32×32 도트 |
| 음악 | 외주 또는 라이선스 확인된 음원, 층(스템) 단위로 |
| ASMR 소리 | 직접 녹음 (브러시, 스펀지, 거품 등) + 효과음 라이브러리 |
| 초기 임시 에셋 | 무료·유료 에셋 팩으로 빠르게 만들고, 나중에 교체 |

## 리스크
| 리스크 | 대응 |
|---|---|
| 범위가 너무 큼 | 단계마다 "재미 검증"을 통과해야 다음으로 |
| 도트 3D 룩이 안 예쁨 | M0에서 룩부터 확정. 안 되면 2D 탑다운으로 전환 |
| 모바일 성능 | 저해상도 렌더, 품질 설정, 저사양 기기 테스트 |
| P2P 연결 실패·IP 노출 | TURN 추가, 공개 채널은 서버 방식으로 전환 계획 |
| iOS PWA 제약 | 방치는 돌아왔을 때 계산, 푸시는 설치 유도 후 |
| 에셋 제작량 | 복셀·도트 규격 통일, 데이터 주도로 재사용 |
| 저장 데이터 날아감 | 백업 코드, 2단계에서 클라우드 저장 |
