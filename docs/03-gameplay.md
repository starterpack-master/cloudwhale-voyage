# 03. 게임플레이 시스템

## 규칙
1. **아무것도 시들거나 아프지 않다.** 오래 비워도 벌이 없다.
2. **실패 없는 미니게임.** 잘하면 더 많이, 못해도 조금은 받는다.
3. **놓쳐도 다시 온다.** 한정 이벤트는 주기적으로 돌아온다.
4. **경쟁 대신 함께 채우기.** 순위표 없음.
5. **5분도, 2시간도.** 짧게 해도 매듭이 있고, 길게 해도 할 게 있다.
6. **협동은 보너스.** 메인 스토리는 혼자서도 끝낼 수 있다.

## 코어 루프
| 주기 | 루프 | 예시 |
|---|---|---|
| 순간 (1~3분) | 행동 → 바로 보상 | 수확, 낚시, 표류물 줍기, 누리 케어 |
| 세션 (5~20분) | 목표 → 탐험 → 제작·건축 | 주문 2개, 섬 하나 탐험, 방 하나 꾸미기 |
| 장기 (일·주·월) | 성장 → 새 해역 → 새 이야기 | 누리 성장, 장 진행, 시즌 이벤트 |

### 한 번 접속하면
1. 누리의 꼬리 인사 → 뽀뽀의 **항해 일지**로 방치 보상 받기
2. 누리 **ASMR 케어** (무지개 재채기로 오늘의 운세)
3. 등 위 농장 수확·심기
4. 등불항 주문 게시판 확인 → 근처 섬 탐험·채집
5. 제작·요리·꾸미기
6. 친구가 있으면 선단 합류 → 협동 이벤트
7. **자장가 재우기** + 목적지 설정 → 누리가 자면서 항해

## 시간
- **하늘 시계:** 모두가 같은 하늘 시간을 공유. 1 하늘일 = 실제 2시간 (낮 80분 · 노을 10분 · 밤 20분 · 새벽 10분).
- **일일 초기화:** 실제 시간 오전 6시.
- **기운:** 벌목·채광 같은 힘든 일에만 쓴다. 음식·휴식으로 회복. 기운이 없어도 낚시·꾸미기·케어·산책은 계속할 수 있다.

## 농사
- 누리 등의 **이끼흙**에 심고 물 준다. 실제 시간으로 자란다 (10분~12시간). **시들지 않는다.**
- 조건: 물(물뿌리개, 비), 빛(낮 작물·밤 작물), 누리의 1절 「꽃피움」 노래로 성장 가속.
- 품질: 보통 / 반짝 / 무지개. 비료와 근처 장식(허수아비 대신 바람개비·풍경)으로 올린다.

| 해역 | 작물 예시 |
|---|---|
| 새벽 여울 | 구름 목화, 이슬 무, 새벽 딸기 |
| 꽃구름 군도 | 노래꽃, 벚꽃 체리, 꿀 완두 |
| 적운 고원 | 무지개 당근, 번개 고추, 소나기 수박 |
| 노을 해협 | 노을 사과, 단풍 호박, 찻잎 |
| 오로라 빙운해 | 눈꽃 배추, 코코아 콩, 오로라 베리 |
| 별의 바다 | 은하수 쌀, 별딸기, 달빛 튤립 |

- 씨앗은 해역에서 얻지만, 한번 얻으면 어디서든 기를 수 있다. 제철 해역에서 기르면 품질이 조금 오른다.

## 동물
| 동물 | 생산물 | 돌보기 (ASMR) |
|---|---|---|
| 구름양 | 구름솜 | 털 깎기 사각사각, 빗질 |
| 이슬벌 | 이슬꿀 | 벌통 톡톡 |
| 별병아리 | 별알 | 둥지 확인, 쓰다듬기 |
| 달토끼 | 달떡 | 보름달 밤 떡방아 쿵덕쿵덕 |

## 구름낚시
- 지느러미 부두나 섬 가장자리에서 구름 속으로 낚싯줄을 던진다.
- 미니게임: 링이 겹칠 때 톡. 놓쳐도 '구름방울'을 준다.
- 물고기 예: 구름잉어, 솜털복어, 번개장어, 노을송어, 오로라 해파리, 별꼬리치(누리가 가장 좋아하는 간식).
- 도감을 채우면 누리 등에 **구름 수족관**을 지을 수 있다.

## 표류물 줍기 (래프트 요소)
- 누리가 헤엄치면 구름솜 뭉치, 하늘유목, 떠돌이 상자, 유리병이 떠내려온다.
- **갈고리 던지기**로 줍는다. 유리병엔 다른 유저가 띄운 **유리병 편지**가 들어 있기도 하다.
- 업그레이드: 지느러미 그물(항해 중 자동 줍기), 구름솜 채집기, 빗물 저장조.

## 섬 탐험
- 해역마다 **이야기 섬**(고정)과 **떠돌이 섬**(하늘일마다 바뀜)이 있다.
- 떠돌이 섬은 해역·채널·날짜로 만들어져서, 같은 채널 유저는 같은 섬을 본다.
- 채집물은 **유저마다 따로** 생긴다. 먼저 캐 가는 경쟁이 없다.
- 숨은 것: 보물 상자, 노래조각, 잃어버린 물건, 퍼즐.

## 모험: 잔향에 응답하기
- 전투는 없다. 잊힘의 바다와 섬 곳곳에 **잔향**이 있다. 대답받지 못한 노래와 마음이 그림자처럼 남은 것이다.
- **듣기:** 잔향에 다가가면, 그 잔향이 품은 짧은 기억 조각(몇 초의 장면과 소리)이 흐른다.
- **응답하기:** 기억에 맞는 것으로 대답한다. 틀려도 벌은 없고, 잔향이 기억을 한 번 더 들려준다.

| 잔향이 품은 기억 (예) | 응답 |
|---|---|
| 끝내 건네지 못한 선물 | **선물:** 기억 속 물건을 찾아 건넨다 |
| 캄캄한 길에서 누군가를 기다리던 밤 | **빛:** 등불을 밝히거나 메아리를 울린다 |
| 중간에 끊긴 노랫소리 | **소절:** 배운 소절로 이어 부른다 |

- 응답받은 잔향은 작은 빛의 정령 **울림**이 되어 누리 등으로 따라온다. 울림은 방치 일꾼이 된다.
- **잊힘의 유적:** 심운 잠수로 들어가는 5~10분짜리 탐험 구역. 빛 퍼즐, 떠다니는 발판, 잃어버린 물건 찾기. 2인 협동 퍼즐은 혼자일 때 울림이 도와준다.
- **큰 잔향:** 장 클라이맥스와 협동 이벤트에 나오는 오래된 잔향. 여러 기억이 겹쳐 있어, 다 같이 응답한다.

## 제작
| 작업대 | 만드는 것 |
|---|---|
| 목공 작업대 | 건축 자재, 가구, 도구 |
| 구름 베틀 | 천, 옷, 커튼, 러그 (모아에게 배움) |
| 별가마 | 유리, 도자기, 조명 |
| 향기 공방 | 향초, 향주머니 (아늑함 보너스) |
| 염색 통 | 옷·가구 색 바꾸기 |
| 악기 공방 | 오카리나, 풍경, 오르골 |
| 케어 도구 공방 | 브러시, 스펀지, 깃털 같은 ASMR 케어 도구 ([04-whale.md](04-whale.md#asmr-케어)) |
| 요리대 | 요리 |

- 레시피는 탐험, NPC 우정, 승객, 누리의 꿈에서 얻는다.
- 오래 걸리는 제작은 오프라인 동안 진행된다.

## 요리
- 예: 첫봄빵, 무지개 샐러드, 솜사탕, 별딸기 타르트, 오로라 코코아, 달떡 꼬치, 노을 사과 파이.
- 효과: 기운 회복, 이동 속도, 낚시 운, **포근함**(방치 보상 증가).
- 같은 공간의 친구와 나눠 먹으면 모두에게 효과가 적용된다.

## 건축과 꾸미기
| 층 | 내용 | 배치 |
|---|---|---|
| 지형 블록 | 이끼흙, 잔디, 모래, 돌, 구름솜, 물, 나무 데크 | 격자, 높이 0~6단 |
| 구조물 | 벽, 바닥, 지붕, 창, 문, 계단, 울타리, 다리 | 조립식 |
| 가구·장식 | 테이블, 침대, 화분, 소품, 벽걸이 | 격자 + 90° 회전, 위에 올리기 |
| 조명 | 등불, 전구 줄, 반딧불 병 | 밤 연출과 연결 |
| 기능 건물 | 작업대, 벌통, 수족관, 온천, 새집, 풍차 | 격자 |

- 마인크래프트식 **블록**(지형) + 스타듀식 **가구**(장식). 모바일 조작을 위해 블록 높이는 6단까지.
- 집 안은 따로 꾸미는 **인테리어 모드** (벽지, 바닥재, 가구).
- 편의 기능: 되돌리기, 복사·붙여넣기, **설계도 모드**(재료 없이 먼저 배치 → 재료가 모이면 완성).
- **아늑함 점수:** 가구 세트, 조명, 식물, 향기로 구역별 점수가 매겨진다. 높으면 누리 기분·승객 만족·방치 보상이 조금씩 오른다. 보너스일 뿐 필수는 아니다.
- **구름 뗏목:** 누리가 아직 작을 때 뗏목을 밧줄로 매달아 공간을 넓힌다 (최대 4개, 각 8×8).
- 설계도 공유와 테마 콘테스트는 [05-multiplayer.md](05-multiplayer.md) 참고.

## 노래
- 노래조각 하나 = 음 하나. 5개를 모으면 소절 하나가 완성된다. 조각마다 그 소절에 얽힌 짧은 이야기가 담긴 **이야기 수집품**이다.
- **부르기:** 배운 소절은 노래 메뉴에서 한 번 탭으로 부른다 (멜로디 입력 없음). 누리가 노래하고 능력이 발동한다. (소절별 능력: [04-whale.md](04-whale.md#노래-능력))
- **인사 노래:** 누리가 친구를 만나면 부르는 짧은 멜로디. 여러 프리셋 중 고르기만 한다 (작곡 기능 없음). 엔딩의 「답가」에 자동으로 엮인다.

## 친구 (NPC 우정)
- 선물, 대화, 부탁으로 우정이 오른다 (우정 10단계). 단계마다 우정 이벤트가 열린다.
- 친해지면 누리 등으로 이사 오는 **이웃**이 된다.

## 승객
- 손님을 태우고, 취향대로 집을 지어 주고, 소원을 들어준다. 목적지에 내리면 기념품을 남긴다.
- 머무는 동안 매일 부탁 하나를 하고, 작은 생산(방치)을 한다.

## 옷과 사진
- 옷 만들기(구름 베틀), 염색, 코디 저장.
- **누리 꾸미기:** 꽃관, 지느러미 리본, 별 스티커, 해초 모자 ([04-whale.md](04-whale.md)의 모자 놀이).
- 사진 모드: 가로·세로 프레임, 필터, 포즈, 스티커, 누리 표정.

## 도감
구름물고기 · 하늘새와 나비 · 꽃 · 별자리 · 노래조각 · 누리의 꿈 · 잃어버린 물건 · **고래 행동**(누리가 보여 준 행동 + 실제 고래 이야기)

## 경제
- 화폐: **조가비**. 등불항 시장, 주문 게시판, 마르의 상점, 퀘스트로 번다.
- **주문 게시판:** 매일 NPC 주문 3개.
- 유저끼리 거래는 초기에는 없다. 이유는 [05-multiplayer.md](05-multiplayer.md#경제) 참고.

## 방치 (오프라인)
| 항목 | 일어나는 일 |
|---|---|
| 자면서 항해 | 목적지를 정하고 재우면 누리가 자면서 헤엄쳐 간다. 도착하면 그곳 재료를 모은다 |
| 수염 필터 | 헤엄치며 구름을 들이마셔 재료를 걸러 모은다 |
| 작물·동물 | 계속 자란다 |
| 울림·승객·이웃 | 맡긴 일(채집, 물 주기, 제작)을 한다 |
| 누리의 꿈 | 가끔 꿈 조각(이야기 카드)과 작은 선물을 가져온다 |

- 최대 12시간까지 쌓인다 (업그레이드로 24시간).
- 돌아오면 뽀뽀가 쓴 **항해 일지**가 나온다: "누리가 분홍 구름을 세 번 들이마셨다. 구름잉어가 경주를 걸어왔고, 나는 품위를 지키느라 져 줬다."
- 오래 쉬고 와도 누리는 반가워할 뿐, 섭섭해하지 않는다.
- 푸시 알림(선택): "누리가 노을 해협에 도착했어요 🌅" — 하루 최대 2회.

## 반복 콘텐츠
| 주기 | 콘텐츠 |
|---|---|
| 매일 | ASMR 케어, 주문 3개, 무지개 운세, 유리병 편지, 고래의 축복 |
| 하늘일마다 (2시간) | 떠돌이 섬 교체, 밤 이벤트 |
| 매주 | 설계 콘테스트, 선단 목표, 마르 한정 물건 |
| 시즌 (4~6주) | 대회유, 계절 축제, 새 옷·가구 세트 |
