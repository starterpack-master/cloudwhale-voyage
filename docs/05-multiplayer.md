# 05. 멀티플레이와 소셜

## 원칙
- **혼자여도 온전하게, 함께라면 더 풍성하게.**
- **경쟁 없음.** PvP·순위표 없이 함께 채우는 목표만.
- **안전 먼저.** 모르는 사람과는 이모트·스티커·정해진 문장만.
- **서버 없이 시작.** 실시간은 유저끼리 직접 연결(P2P), 저장·편지는 관리형 백엔드 ([07-tech.md](07-tech.md#네트워크)).

## 해금
| 시점 | 해금 |
|---|---|
| 프롤로그 후 | 같은 해역의 다른 고래가 보임, 이모트, 유리병 편지 줍기 |
| 1장 완료 | 선단, 고래 방문, 협동 이벤트, 친구, 우편 |
| 2장 이후 | 고래 잇기 장터, 설계도 공유, 콘테스트 |

## 만나는 곳
| 공간 | 인원 | 설명 |
|---|---|---|
| 해역 채널 | 권장 8명 (최대 12명) | 같은 해역·채널의 고래들이 한 하늘에서 헤엄친다. 자동 배정 |
| 등불항 광장 | 채널당 최대 12명 | 시장, 게시판, 축제가 열리는 마을 |
| 선단 | 최대 6명 | 친구끼리 만드는 전용 방. 초대 코드로 입장 |
| 고래 방문 | 주인 + 5명 | 친구 고래 등 위로 놀러 가기 |

## 대화
| 수단 | 모르는 사람 | 친구 |
|---|---|---|
| 이모트 (꼬리 인사, 하트, 박수, 졸려…) | ✅ | ✅ |
| 스티커 | ✅ | ✅ |
| 정해진 문장 ("안녕!", "같이 낚시할래?", "고마워!") | ✅ | ✅ |
| 자유 채팅 (필터 적용) | ❌ | ✅ (끌 수 있음) |

- **고래 인사:** 두 고래가 가까워지면 서로 인사 노래(프리셋)를 주고받으며 화음을 이룬다. 말없이도 인사가 된다.
- **함께 효과:** 같은 공간에서 같은 활동(낚시, 채집, 요리)을 하면 희귀 확률이 조금 오른다.

## 선단
- 1장 이후 결성. 이름, 깃발 색, 문양을 정한다.
- 편대 항해: 줄지어 헤엄치면 뒤따르는 고래가 빨라진다.
- 선단 목표: 매주 함께 채우는 목표 → 전원 보상.

## 고래 방문
| 권한 | 할 수 있는 것 |
|---|---|
| 구경 | 걷기, 앉기, 사진, 방명록 |
| 도움 | + 물 주기, 누리 케어, 동물 쓰다듬기 (하루 한도) |
| 같이 짓기 | + 설계도 모드로 함께 배치 (주인이 확정) |

- 기본값은 '친구만 구경'.
- **방명록:** 발자국 스티커와 한마디.
- **친구가 접속해 있지 않을 때:** 마지막으로 저장된 모습을 구경하고, 방명록과 물 주기 도움을 남길 수 있다. 친구가 돌아오면 반영된다.

## 협동 이벤트
| 이벤트 | 인원 | 핵심 |
|---|---|---|
| 구름방울 고리 | 3~8 | 박자 맞춰 거품 고리 완성 |
| 고래 요람 | 2~6 | 어미가 잠수하는 동안 아기 고래들 곁 지키기 |
| 아기 고래 엄마 찾기 | 2~6 | 편대로 감싸고 길 밝히기 |
| 달빛 쉼 | 해역 전체 | 보름달 밤, 나란히 떠서 모닥불 야영 |
| 고래 잇기 장터 | 2~6 | 등과 등을 이어 노점 마을 |
| 「온기의 밤」 | 전 서버 | 4장 월드 이벤트, 각자 등불 하나씩 |
| 대회유 | 전 서버 | 시즌 공동 게이지와 축제 |

상세는 [04-whale.md](04-whale.md#상세-협동-이벤트) 참고.

## 비동기 소통
실시간으로 안 만나도 연결되는 장치예요. "많은 사람이 함께 사는 하늘"이라는 느낌은 주로 여기서 나와요.

| 기능 | 설명 |
|---|---|
| 포롱 우편 | 친구에게 편지 + 선물 1개. 실제 시간으로 몇 분~몇 시간 뒤 도착 (포롱이 길치라서) |
| 유리병 편지 | 모르는 누군가에게 띄우는 응원 한마디 (정해진 문장 + 스티커). 다른 유저가 표류물로 줍는다. 답장은 '고마워' 반응만 |
| 방명록 | 친구 고래에 남기는 발자국과 한마디 |
| 설계도 갤러리 | 내 건축을 올리고, 남의 설계도를 받아 짓기 |
| 테마 콘테스트 | 매주 테마 ("비 오는 날의 찻집"). '좋아요'만 있고, 순위 대신 추천 전시 |
| 월드 게이지 | 대회유, 「온기의 밤」 같은 전 서버 목표 |

## 경제
- 유저끼리 **거래·시장 없음** (초기). P2P 구조에서는 아이템 복사나 사기를 막기 어렵고, 경쟁 없는 경제를 지키기 위해서예요.
- 대신 **선물:** 하루 5회, 받은 선물은 다시 보낼 수 없음.
- 장터는 조가비 대신 **교환권**으로 운영.

## 안전
| 장치 | 내용 |
|---|---|
| 대화 단계 | 모르는 사람 = 이모트·스티커·정해진 문장. 자유 대화는 서로 친구일 때만 |
| 필터 | 닉네임·채팅·편지 금칙어 |
| 차단 | 서로 안 보이게 (같은 채널이어도) |
| 신고 | 대화·편지·방명록·설계도. 누적되면 자동 숨김 |
| 위치 보호 | 친구가 아니면 내가 어느 해역·채널에 있는지 알 수 없음 |
| 개인정보 | 실명·연락처 없음. 프로필은 닉네임과 누리 사진만 |
| 연결 보호 | P2P는 연결된 상대에게 IP가 보일 수 있음 → 공개 채널은 중계 연결 검토 ([07-tech.md](07-tech.md#p2p의-한계와-대응)) |

## 기능별 연결 방식
| 기능 | 방식 |
|---|---|
| 해역 채널, 선단, 방문, 협동 이벤트 | 실시간 P2P |
| 친구, 우편, 유리병, 방명록, 갤러리, 콘테스트, 월드 게이지, 클라우드 저장 | 관리형 백엔드 |
| 플랑크톤 밤, 보름달, 떠돌이 섬 | 서버 없음 (하늘 시계로 계산) |
