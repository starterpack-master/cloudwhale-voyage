# 06. 아트와 사운드

## 한 줄
**"맑은 파스텔 + 둥근 도트 캐릭터 + 신비로운 빛의 하늘."**

## 스타일: 픽셀 2.5D
- 3D 월드(복셀·로우폴리) + 2D 도트 캐릭터를 **저해상도로 그린 뒤 정수 배율로 확대**해요.
- 3D라서 빛·안개·카메라 연출이 자유롭고, 저해상도라서 전부 도트처럼 보여요. (구현: [07-tech.md](07-tech.md#렌더링-파이프라인))

| 규칙 | 값 |
|---|---|
| 텍셀 밀도 | 1타일 = 16px |
| 캐릭터 | 32×32 프레임, 2.5등신, 4방향, 걷기 6프레임 |
| 외곽선 | 검정 금지 → 짙은 라벤더 1px |
| 그림자 | 검정 금지 → 보라·파랑 톤 |
| 셰이딩 | 툰 3단 + 림라이트 |
| 반투명 | 디더링으로 표현 (도트 느낌 + 모바일 성능) |
| 움직임 | 눌렸다 되돌아오는 부드러운 탄성 애니메이션 (squash & stretch) |

## 귀여움 규칙
- 귀여움은 **캐릭터 디자인**에 쓴다. 풍경·건축·UI 문구는 절제되고 신비롭게.
- 동그란 실루엣, 뾰족한 모서리는 최소로.
- 큰 눈, 작은 입, 볼터치.
- 아이템을 얻으면 살짝 떠올랐다가 빛을 남기며 내려앉는다.
- 누리와 동물은 가만히 있어도 숨 쉬듯 살짝 부풀었다 줄었다 한다.

## 누리 디자인
- 동글동글 물방울 몸, 짧고 통통한 지느러미, 하트 모양 꼬리 끝.
- 하늘색 등 → 라벤더 옆구리, 크림색 배 주름.
- 볼의 별 주근깨(밤에 반짝), 하이라이트 2개 들어간 큰 눈, 숨구멍 위 새싹.
- 표정: 기본, 신남, 졸림, 간지러움, 놀람, 뿌듯, 노곤함(케어 중).

## UI
- 둥근 모서리, 크림색 종이 패널, 도트 아이콘.
- 글꼴: 한글 도트 글꼴(예: 갈무리 같은 오픈 라이선스 글꼴) + 긴 글용 둥근 글꼴.
- 버튼은 크게(44pt 이상), 주요 버튼은 엄지가 닿는 곳에: 가로는 좌우 아래 모서리, 세로는 화면 아래쪽 1/3.

## 카메라
- **가로 기본, 세로 지원.** 화면 방향에 맞춰 카메라가 돌아, 고래의 긴 몸이 늘 화면의 긴 쪽에 놓여요 (가로: 좌우로 길게, 세로: 위아래로 길게).
- 방향을 바꾸면 카메라가 부드럽게 돌며 전환되고, 등 위 배치·선택 상태는 그대로 유지돼요.
- 비스듬히 내려다보는 쿼터뷰, 누리 등이 화면 중앙.
- 줌은 도트가 뭉개지지 않게 정수 배율(2×, 3×, 4×)만.
- ASMR 케어 중에는 누리 얼굴·몸에 가까이 붙는 클로즈업.

## 사운드
### 음악
- **낮은 맑고 경쾌하게:** 칼림바, 하프, 플루트, 피아노, 피치카토 현악, 먼 고래 울음.
- **밤과 잊힘의 바다는 신비롭게:** 오르골, 신스 패드, 글라스 하모니카, 긴 리버브.
- **진행할수록 풍성해지는 메인 테마:** 「누리의 노래」는 소절을 되찾을 때마다 악기가 하나씩 늘어나요. 처음엔 누리의 서툰 한 음으로 시작해서, 엔딩엔 모든 고래와 고래지기의 합창이 돼요.

| 해역 | 악기 | 분위기 |
|---|---|---|
| 새벽 여울 | 칼림바, 오르골, 피아노 | 맑은 새벽 |
| 꽃구름 군도 | 플루트, 하프, 피치카토 | 봄의 축제 |
| 적운 고원 | 팀파니, 현악, 빗소리 | 폭풍, 그리고 갠 하늘 |
| 노을 해협 | 어쿠스틱 기타, 아코디언 | 그리운 오후 |
| 오로라 빙운해 | 글로켄슈필, 첼로, 작은 종 | 고요하고 따뜻한 겨울 |
| 별의 바다 | 첼레스타, 신스 패드, 허밍 합창 | 꿈과 별빛 |
| 잊힘의 바다 | 오르골, 글라스 하모니카, 먼 고래 울음 | 깊고 고요한 기억 |

### ASMR 사운드 (중요)
- 케어·생활 소리는 **귀 가까이에서 들리는 질감**으로 녹음·제작: 사각사각, 뽀득뽀득, 스슥, 톡, 두근두근, 토닥토닥, 바삭바삭.
- 케어 중에는 BGM이 살짝 작아지고 케어 소리가 앞으로 나와요.
- 도구마다 소리가 달라요 (나무 브러시 vs 구름 스펀지).
- 이어폰을 끼면 문지르는 위치에 따라 소리가 좌우로 움직여요.

### 효과음
- 둥글고 부드럽게: 맑은 종, 물방울, 나무 울림, 낮은 고래 울음. 날카로운 고음은 쓰지 않아요.
- UI는 작은 종·실로폰 소리로 통일.

### 인사 노래
- 유저는 **여러 프리셋 중 고르기만** 해요 (작곡 기능 없음).
- 프리셋은 모두 5음 음계라 서로 겹쳐도 어울리고, 재생할 때 지금 BGM의 조와 박자에 자동으로 맞춰요. 엔딩의 「답가」도 이 방식으로 자동으로 엮어요.

## 진동
- 케어, 수확, 낚시 입질에 짧은 진동 (지원 기기에서만. iOS 브라우저는 지원이 제한적이라 소리·이펙트로 대신).

## 접근성
- 흔들림 줄이기(멀미 방지), 번쩍임 없음, 자막, 글자 크기, UI 대비 강화.
